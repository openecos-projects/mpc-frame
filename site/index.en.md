# mpc-frame Documentation

[中文说明](index.md)

`mpc-frame` connects independent RTL designs to one chip top through a uniform
66-bit bidirectional payload interface. Start with the [Frame mode overview](docs/frame-mode.en.md),
then follow the [user integration guide](docs/user-guide.en.md).
