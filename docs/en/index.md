# mpc-frame Documentation

[中文说明](../cn/index.md)

`mpc-frame` connects independent RTL designs to one chip top through a uniform
66-bit bidirectional payload interface. Start by
[getting the User Kit](user-kit.md), then follow the
[user integration guide](user-guide.md).
