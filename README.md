# mpc-frame

`mpc-frame` 是一个用于拼片的顶层空壳模板工程。

与 `mpc-soc` 不同，本工程不包含完整外设 IP、`new-ip/` 模块集合或 `perip/` 外设目录，也不实例化 CPU、总线、外设、存储器模型或仿真模型。拼片用户可以使用全部剩余的 73 个用户自定义 pad，具体 IO 功能由用户设计决定。

当前保留的顶层接口：

- `clock`：输入时钟。
- `reset`：输入复位。
- `user_io[72:0]`：73 个用户自定义双向 pad。

相关文件：

- `build/GenerateTop.v`：空的拼片顶层 Verilog 模板。
- `docs/io-map.md`：用户自定义 pad 编号说明。

## 当前状态

本工程是一个 frame/template 级别的参考工程，只提供拼片顶层入口，不代表完整可生产的 SoC 工程。使用时需要根据目标设计补充具体模块、互连、IO 方向控制、时序约束和验证流程。

`user_io` 默认没有任何预定义协议或固定功能。用户需要自行决定每个 pad 的用途、方向、复用方式、电气约束和内部连接关系。

如需参考完整外设和 IP 目录，请查看同级的 `mpc-soc` 工程。
