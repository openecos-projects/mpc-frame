# PSRAM

[中文说明](README.md)

## Features
* Support SerialRAM(SPI, QPI and OPI mode)
* Programmable prescaler
    * max division factor is up to 2^20
    * can be changed ongoing
* Maskable overflow interrupt
* Static synchronous design
* Full synthesizable
