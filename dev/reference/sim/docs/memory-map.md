# 地址空间

[English](memory-map.en.md)

| 区域 | 基地址 | 大小 | 说明 |
| --- | ---: | ---: | --- |
| CLINT | `0x0201_0000` | `0x0001_0000` | NPC 本地中断 |
| PLIC | `0x0c00_0000` | `0x0040_0000` | UART/GPIO 外部中断 |
| UART0 | `0x1000_0000` | `0x0000_1000` | UART16550 |
| RCU | `0x1000_2000` | `0x0000_1000` | 时钟与复位控制 |
| GPIO0 | `0x1010_0000` | `0x0000_0100` | GPIO[31:0] |
| GPIO1 | `0x1010_0100` | `0x0000_0100` | GPIO[53:32]，有效 22 位 |
| SPI Flash | `0x3000_0000` | `0x0100_0000` | XIP 取指窗口 |
| PSRAM | `0xc000_0000` | `0x0080_0000` | 单颗 8 MiB RAM |

未列出的旧外设地址不属于当前参考设计接口。
